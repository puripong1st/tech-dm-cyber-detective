# Brand and asset specification

## ตัวตนที่มีอยู่จริง

- ชื่อหลักที่ใช้สม่ำเสมอ: **Cyber Shield Detective**
- คำอธิบายภาษาไทย: **เกมและสื่อการเรียนรู้กฎหมายไซเบอร์สำหรับ ม.3**
- กลุ่มสาระหลัก: พ.ร.บ.คอมพิวเตอร์ พ.ศ. 2560, PDPA, การใช้เทคโนโลยีอย่างปลอดภัยและรับผิดชอบ
- บุคลิก: ครูที่ทันสมัยและเป็นมิตร + เกมสืบสวนที่ชวนลงมือคิด ไม่ใช่บริษัท cyber-security และไม่ใช่สำนักงานกฎหมาย

## สินทรัพย์ที่อนุญาตให้ใช้

- `../../favicon.png` — โลโก้หลักใน header เท่านั้น ต้องกำหนด width/height และ alt ที่เหมาะสม
- `../../assets/pdpa_icon.png` — ใช้กับรายการ PDPA ได้ ไม่ใช้ซ้ำเป็นของตกแต่งทั่วหน้า
- `../../assets/mascot_scan.png`, `../../assets/mascot_law.png`, `../../assets/mascot_judge.png` — ใช้ได้ไม่เกินหนึ่งภาพเด่นต่อ direction หากช่วยเล่าเส้นทางผู้ใช้
- ห้ามดึงภาพ stock หรือภาพ AI เพิ่ม เพราะความเข้าใจผลิตภัณฑ์ไม่ได้ขึ้นกับภาพถ่าย

## สีตั้งต้นจากเนื้อหา

- Navy ink: `#13233B` หรือค่าที่ใกล้เคียง — ความน่าเชื่อถือและโล่ไซเบอร์
- Signal blue: `#2477D4` — การกระทำหลัก/ลิงก์
- Alert amber: `#F2B544` — หมายเลขคดีหรือ focus cue ใช้พื้นที่น้อย
- PDPA mint: `#33A77B` — แยกหัวข้อข้อมูลส่วนบุคคล
- Warm paper: `#F7F4EC` และ white: `#FFFFFF` — พื้นที่พักสายตา
- Charcoal: `#20242A` — ตัวอักษร หลีกเลี่ยงดำสนิทบนพื้นที่ใหญ่

แต่ละ direction อาจปรับ chroma/lightness เพื่อให้สอดคล้องสไตล์ แต่จำกัดสีมี chroma 2–3 สีต่อหน้าและต้องอธิบายที่มาจากโลโก้/สัญญาณเตือน/PDPA ไม่ใช้ม่วง–ชมพู gradient แบบ tech template

## ตัวอักษร

- Body ต้องอ่านภาษาไทยสบาย: Sarabun, IBM Plex Sans Thai, Noto Sans Thai หรือ system fallback
- Display เลือกให้เข้าทิศทางแต่ต้องไม่ลดความอ่านง่ายของภาษาไทย
- หลีกเลี่ยง Inter เป็นฟอนต์หลักภาษาไทยและหลีกเลี่ยงการใช้ Kanit หนาหลายระดับทั้งหน้าแบบเดิม
- body 16px ขึ้นไป, line-height 1.6 โดยประมาณ, หัวข้อไม่ใช้ตัวพิมพ์ใหญ่ภาษาอังกฤษยาว

## น้ำเสียงข้อความ

- ใช้คำกริยาที่บอกงาน: “เริ่มสืบคดี”, “เปิดสไลด์บทเรียน”, “สร้างใบงาน PDPA”, “ดูเส้นทางการสอน”
- เป็นมิตรแต่ไม่เด็กเกินไป ไม่ใช้ emoji เป็นเครื่องหมายทุกหัวข้อ
- หลีกเลี่ยงคำว่า “อันดับ 1”, “ดีที่สุด”, “การันตี”, “ครบที่สุด” และสถิติที่ไม่มีที่มา
- หากกล่าวถึง AI ให้ใช้ข้อความตามความจริงว่า “มีระบบช่วยประเมินคำตอบด้วย Gemini AI” ไม่ระบุรุ่นหรือความแม่นยำ

## สิ่งที่ต้องรักษา

- URL ภายในทั้งหมดต้องเป็นไฟล์จริงในโครงการ
- canonical production เดิมคือ `https://tech-dm-cyber-detective.vercel.app/`
- เครดิตผู้จัดทำใช้ชื่อ “Cyber Shield Detective Team” ตาม metadata ปัจจุบันจนกว่าผู้ใช้จะให้ชื่อบุคคล/โรงเรียนที่แม่นยำกว่า
- แสดงข้อความว่าเป็นสื่อเพื่อการเรียนรู้ ไม่ใช่คำปรึกษาทางกฎหมาย
