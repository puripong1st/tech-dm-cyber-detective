# Product facts: Canva interaction reference

ตรวจสอบเมื่อ 23 สิงหาคม 2569 เพื่อใช้เป็น “interaction reference” เท่านั้น โดยจะไม่ใช้โลโก้หรือคัดลอกหน้าตา Canva ตรง ๆ ในต้นแบบ

- Canva จัดหมวดงานแก้ไขเป็น templates/layouts, elements, images/photos, text/fonts, page settings/guides/layers และ editor navigation ตามศูนย์ช่วยเหลือทางการ
- ระบบทางลัดของ Canva ครอบคลุม undo/redo, ซ่อนแถบข้าง, เพิ่ม text/rectangle/line/circle, group/ungroup, lock, จัดลำดับชั้นหน้า–หลัง, เลื่อนด้วยปุ่มลูกศร, zoom และ page views
- เมื่อเลือกกล่องข้อความ จะมี floating/context toolbar สำหรับ duplicate, delete และจัดรูปแบบข้อความ
- การจัดองค์ประกอบรองรับ group, layer, alignment, corner-handle resize และ rotate handle
- ข้อมูลเหล่านี้ใช้สรุป “รูปแบบการทำงาน” ที่ผู้ใช้คุ้นเคย: tool rail → asset panel → central canvas → contextual properties → page/zoom controls
