# คู่มือกระดานสร้างใบงาน PDPA (`pdpa_assignment_board.html`)

**PDPA Assignment Board** คือสตูดิโอสร้างใบงานดิจิทัลสไตล์ Canva สำหรับนักเรียน ม.3 ผู้เรียนสามารถสรุปคดี ตอบคำถามวิเคราะห์ 3 ภารกิจ อัปโหลดหลักฐาน เพิ่มกล่องข้อความ โพสต์อิท สติกเกอร์ และปรับสีหรือรูปแบบกระดาษได้อย่างอิสระ

ระบบส่งงานใช้ **PDF A4 แนวนอนเพียงรูปแบบเดียว** เพื่อรักษาตำแหน่ง Q1, Q2, Q3 ลิงก์ข่าว ตัวอักษร และเส้นกรอบให้คมชัดเมื่อนำไปส่งหรือพิมพ์

## 1. ขั้นตอนใช้งาน

1. กรอกชื่อ ชั้น และเลขที่นักเรียน
2. เพิ่มภาพหลักฐานและลิงก์ข่าวที่ใช้เป็นแหล่งข้อมูล
3. เขียนสรุปเหตุการณ์และตอบคำถาม Q1, Q2 และ Q3
4. ตกแต่งด้วยกล่องข้อความ โพสต์อิท สติกเกอร์ ไฮไลต์ และธีมกระดาษ
5. ตรวจตัวอย่าง A4 ทางด้านขวา
6. กด **พิมพ์ / บันทึก PDF**

ข้อมูลระหว่างทำงานยังบันทึกอัตโนมัติในเบราว์เซอร์ เพื่อป้องกันงานหายเมื่อรีเฟรชหน้า ส่วนปุ่ม “เริ่มคดีใหม่” ใช้ล้างข้อมูลเดิมเมื่อผู้ใช้ยืนยัน

## 2. การบันทึก PDF ที่แนะนำ

ในหน้าต่างพิมพ์ของเบราว์เซอร์ให้ตั้งค่า:

- กระดาษ: **A4**
- การวางแนว: **แนวนอน (Landscape)**
- ระยะขอบ: **ไม่มี (None)**
- ขนาด: **100%** หรือ **พอดีกับพื้นที่พิมพ์**
- กราฟิกพื้นหลัง: **เปิดใช้งาน**
- ปลายทาง: **Save as PDF** หรือ **Microsoft Print to PDF**

ก่อนเปิดหน้าพิมพ์ ระบบจะยกเลิกการเลือกวัตถุตกแต่ง ซ่อนส่วนควบคุม และจัดแม่แบบให้มีขนาด A4 คงที่

## 3. เกณฑ์ประเมินใบงาน

| มิติ | ดีเยี่ยม | ควรปรับปรุง |
|---|---|---|
| ความถูกต้องของเนื้อหา | ระบุข้อมูลส่วนบุคคล การละเมิด และเหตุผลได้ชัดเจน | เนื้อหาคลาดเคลื่อนหรือขาดเหตุผล |
| การแก้ไขปัญหา | เสนอการระงับเหตุและการเยียวยาที่ทำได้จริง | คำตอบกว้างและไม่เชื่อมกับคดี |
| การป้องกันระยะยาว | เสนอมาตรการด้านสิทธิ์ ระบบ และบุคลากรอย่างเป็นขั้นตอน | มีเพียงคำเตือนทั่วไป |
| การสื่อสาร | จัดลำดับเนื้อหาอ่านง่ายและอ้างอิงแหล่งข่าวครบ | ข้อความล้นกรอบหรือลิงก์ไม่ครบ |

## 4. การแก้ปัญหาที่พบบ่อย

| ปัญหา | วิธีแก้ |
|---|---|
| ปุ่ม PDF ขอข้อมูลนักเรียน | กรอกชื่อ ชั้น และเลขที่ให้ครบก่อนส่งออก |
| หน้า PDF เป็นแนวตั้ง | เปลี่ยน Orientation เป็น Landscape ในหน้าต่างพิมพ์ |
| สีพื้นหลังไม่ออก | เปิดตัวเลือก Background graphics |
| ข้อความแน่นเกินไป | ย่อข้อความหรือแบ่งประโยคก่อนพิมพ์ ระบบจะช่วยปรับข้อความในช่องหลักให้อยู่ในกรอบ |
| ลิงก์ข่าวยาว | ระบบตัดขึ้นบรรทัดใหม่ในแม่แบบพิมพ์โดยไม่ตัด URL ทิ้ง |
