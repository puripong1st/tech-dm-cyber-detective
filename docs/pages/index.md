# คู่มือหน้า Main Portal Hub (`index.html`)

หน้าแรกของ **Cyber Shield Detective** เป็นศูนย์รวมเกมและสื่อการเรียนรู้ พ.ร.บ.คอมพิวเตอร์ 2560 และ PDPA สำหรับนักเรียน ม.3 และครูผู้สอน โดยใช้ดีไซน์ Direction A แบบ Friendly Geometric ที่อ่านง่ายและลดจำนวนตัวเลือกซ้ำซ้อน

## 1. โครงสร้างหน้า

ผู้ใช้เริ่มต้นได้สองเส้นทาง:

- **นักเรียน** เริ่มจากเกมหลัก 6 คดี หรือเลือกแบบทดสอบและกิจกรรมฉบับเร็ว
- **ครู** ใช้เส้นทางจัดคาบ 3 ขั้น ได้แก่ ปูพื้นด้วยสไลด์ วิเคราะห์คดีด้วยเกม และสร้างชิ้นงาน PDPA

ส่วนเครื่องมือทั้งหมดแบ่งเป็น 3 หมวดที่มองเห็นพร้อมกัน:

1. **เรียนรู้และเล่น** — เกมหลัก 6 คดี เกมฉบับเร็ว 3 คดี PDPA Fast-Pass และแบบทดสอบปรนัย
2. **สื่อและชิ้นงาน** — สไลด์ พ.ร.บ.คอมพิวเตอร์ สไลด์ PDPA 101 และกระดานสร้างใบงาน PDPA
3. **เครื่องมือสำหรับครู** — ศูนย์ควบคุมเกม แดชบอร์ดแบบทดสอบ และคลังคดีพร้อมแนวคำตอบ

## 2. แนวทางใช้ในชั้นเรียน

1. เปิด `presentation.html` หรือ `pdpa_presentation.html` เพื่อปูพื้นคำสำคัญ
2. ให้นักเรียนวิเคราะห์สถานการณ์ใน `cyber_shield_detective.html`
3. สรุปความเข้าใจเป็นชิ้นงานใน `pdpa_assignment_board.html`

หากมีเวลาจำกัด ใช้ `cyber_shield_detective_3.html` หรือ `pdpa_fast_pass.html` แทนกิจกรรมหลักได้

## 3. SEO และ Accessibility

- ใช้ `<html lang="th">` และมี `<h1>` หลักเพียงหนึ่งรายการ
- Title และ Meta Description ระบุคำค้นหลักเกี่ยวกับ พ.ร.บ.คอมพิวเตอร์, PDPA และ ม.3
- มี Canonical URL และ Meta Robots ที่อนุญาตการจัดทำดัชนี
- ฝัง JSON-LD ประเภท `WebSite`, `ItemList` และ `FAQPage`
- ลิงก์ทุกระบบเป็น `<a href>` จริง จึงใช้งานได้แม้ JavaScript ไม่ทำงาน
- มี Skip Link, ลำดับหัวข้อที่ถูกต้อง, Focus State และเมนูมือถือที่รองรับ `aria-expanded`

## 4. การทำงานบนมือถือ

เมื่อหน้าจอกว้างไม่เกิน 900 พิกเซล เมนูหลักจะเปลี่ยนเป็นปุ่ม “เมนู” ส่วน Hero, การ์ดบทบาท, หมวดเครื่องมือ และเส้นทางการสอนจะเรียงเป็นคอลัมน์เดียว ปุ่มและลิงก์สำคัญมีพื้นที่กดไม่น้อยกว่า 44 พิกเซล

## 5. การตรวจสอบก่อนเผยแพร่

- ตรวจว่าลิงก์ภายในทุกไฟล์มีอยู่จริง
- ตรวจ Structured Data ด้วย Schema.org Validator หรือ Google Rich Results Test
- ตรวจ `sitemap.xml` และ `robots.txt` หลังเปลี่ยน URL
- ทดสอบอย่างน้อยที่ 1440×900 และ 390×844 พิกเซล
- ตรวจ Console ว่าไม่มี JavaScript Error

> SEO ทางเทคนิคช่วยให้ Google เข้าใจและเข้าถึงหน้าได้ดีขึ้น แต่ลำดับการค้นหายังขึ้นกับคุณภาพเนื้อหา ความน่าเชื่อถือ ลิงก์อ้างอิง และการแข่งขันของคำค้นด้วย
