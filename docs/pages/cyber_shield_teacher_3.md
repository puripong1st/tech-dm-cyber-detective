# 📖 คู่มือการใช้งานและโครงสร้างระบบ: Teacher Command Center 3 คดี (`cyber_shield_teacher_3.html`)

**Teacher Command Center (3 คดี)** คือ แผงควบคุมคะแนนสดที่ออกแบบมาคู่กับเกมเวอร์ชัน **Fast-Track 3 คดี (`cyber_shield_detective_3.html`)** โดดเด่นด้วยการจัดวางข้อมูลที่กระชับ มอนิเตอร์คะแนนเต็ม 90 คะแนน และระบบพิมพ์รายงานผล **Single-Page A4 PDF** ที่พอดี 1 หน้ากระดาษสมบูรณ์แบบ

---

## 🌟 1. ภาพรวมและวัตถุประสงค์ (Overview & Learning Objectives)

### 🎯 วัตถุประสงค์หลัก
1. **มอนิเตอร์กิจกรรมสืบคดีคาบสั้น (Fast-Paced Classroom Dashboard)**: ติดตามการส่งคำตอบ 3 คดี (9 บทบาท) ของนักเรียนทั้งห้องเรียนในคาบ 50 นาที
2. **รายงานผลประเมินพอดี 1 หน้า A4 (Guaranteed 1-Page Printable Report)**: สรุปคะแนนรายกลุ่ม รายบทบาท และเกรดเฉลี่ยพอดี 1 แผ่นสำหรับแนบ ปพ.5 หรือแฟ้มสะสมงาน
3. **ตรวจสอบความถูกต้องและการทุจริตแบบเรียลไทม์**: แสดงจำนวนครั้งการสลับหน้าจอ (Tab Switches) และประวัติการบันทึกคะแนน

---

## 👨‍🏫 2. สิ่งที่ครู/ผู้สอนควรชี้แนะแก่นักเรียน (Pedagogical Guidelines)

### 💡 แนวทางการใช้งานระหว่างคาบเรียน 50 นาที
- **นาทีที่ 0 - 5**: ครูเปิดหน้า `cyber_shield_teacher_3.html` ฉายบนจอโปรเจกเตอร์เพื่อให้นักเรียนเห็นสถานะเริ่มเกม
- **นาทีที่ 5 - 35**: ให้นักเรียนลงมือสืบคดี ครูสังเกตกลุ่มที่คะแนนต่ำกว่าเกณฑ์เพื่อเข้าไปให้คำแนะนำรายกลุ่ม
- **นาทีที่ 35 - 45**: ครูใช้ฟังก์ชันดูคำตอบของกลุ่มที่ได้คะแนนสูงสุดเพื่อนำมาฉายและอภิปรายถอดบทเรียนร่วมกันทั้งห้อง
- **นาทีที่ 45 - 50**: กดปุ่ม Export PDF บันทึกรายงานผลของทั้งห้องทันที

## 📊 4. เกณฑ์การประเมินและการคิดเกรด (Fast-Track Grading Scale - เต็ม 90 คะแนน)

| ช่วงคะแนน | ระดับผลการเรียน | ความหมาย |
|:---:|:---:|---|
| **72 - 90 คะแนน (80% ขึ้นไป)** | **ดีเยี่ยม (4)** | เข้าใจกฎหมายดิจิทัลและมีทักษะการรับมือเหตุการณ์ในระดับยอดเยี่ยม |
| **63 - 71 คะแนน (70% - 79%)** | **ดีมาก (3.5)** | มีความรู้ความเข้าใจกฎหมายดี สามารถวิเคราะห์และป้องกันได้ถูกต้อง |
| **54 - 62 คะแนน (60% - 69%)** | **ดี (3)** | ผ่านเกณฑ์มาตรฐาน เข้าใจองค์ประกอบความผิดสำคัญ |
| **45 - 53 คะแนน (50% - 59%)** | **พอใช้ (2)** | ผ่านเกณฑ์ขั้นต่ำ ควรทบทวนเรื่องอัตราโทษและมาตรการป้องกันเพิ่มเติม |
| **ต่ำกว่า 45 คะแนน (< 50%)** | **ปรับปรุง (1)** | ไม่ผ่านเกณฑ์ ต้องได้รับการสอนเสริมและทำแบบทดสอบใหม่ |

## 💻 5. ผ่าสถาปัตยกรรมโค้ดและการทำงานเชิงลึก (Detailed Code Breakdown)

### 🖨️ ระบบพิมพ์รายงาน A4 หน้าเดียวพอดี
```css
@media print {
    @page {
        size: A4 portrait;
        margin: 5mm 6mm;
    }
    .print-table {
        font-size: 10.5pt !important;
        line-height: 1.25 !important;
    }
    .print-table th, .print-table td {
        padding: 4px 6px !important;
    }
}
```
